AV 파일명 변경기 개선본 (AutoHotkey v2 전용)

사용 방법
1. 5개의 .ahk 파일을 모두 같은 폴더에 놓으세요.
2. 기존 ActressDB.ini를 사용하려면 같은 폴더에 복사하세요.
3. DB.ahk: 배우/품번 검색 및 수집. Rename.ahk: 파일 이름 변경.
4. 두 프로그램의 동시 DB 쓰기는 피하세요. 기존 파일의 복사본으로 먼저 확인하세요.

주요 변경
- 동영상 파일 덮어쓰기 금지. 이름 충돌은 실패로 기록하고 원본 유지.
- 모든 인식 가능한 VR/해상도/PART/CD/DISC/DISK 태그 보존.
- ABC-123-1 / ABC-123_02 형태 분할 번호를 PART1 / PART02로 보존.
- 입력 목록 중복 제거 및 동영상 확장자 재확인.
- 개별 파일 검색/파싱 오류를 기록하고 다음 파일 계속 처리.
- 예외 발생 시 버튼 복구 및 작업 시작 전 클립보드 복원.
- DB 읽기 캐시, 쓰기 실패 보고, 디스크 저장 후 캐시 반영.
- 표준 이름은 StandardNames 섹션에 별도 저장.
- DB.ahk의 중복 DB/브라우저/이름 파싱 코드를 공통 모듈로 통합.
- 수집 시 배우의 모든 이름 토큰 일치 필요. 페이지별로 수집 내용 저장.
- 기존 두 페이지 연속 신규 없음 조기 종료 제거 (이전 작품 누락 방지).
- JAVGURU에서 품번이 일치하는 제목만 선택; 임의 첫 링크 이동 제거.
- 정규식 입력 이스케이프, 밑줄 주변 품번 인식, INI 분할 인자 수정.
- 품번 없는 파일은 DB에 등록된 이름이 있을 때만 정규화.

DB 인코딩
새 INI는 Windows INI API에 맞는 UTF-16으로 생성합니다.
기존 UTF-8 BOM INI는 원본을 .utf8-backup-날짜-번호 파일로 복사한 후 변환합니다.
BOM 없는 기존 파일은 Windows 시스템 코드 페이지로 읽으므로, 한글이 깨진 경우
원본을 보관하고 Windows 편집기에서 UTF-16 LE로 저장해 사용하세요.
기존 별칭은 유지하며, 신규 DB에는 특정 배우의 별칭을 임의로 넣지 않습니다.

검증 범위와 제한
이 패키지는 Linux에서 수정했습니다. 문자열/괄호 균형 및 Include 경로를 점검했습니다.
AutoHotkey 실제 실행, Windows GUI, 브라우저 및 사이트 실응답은 검증하지 못했습니다.
사이트 텍스트 구조에 의존하는 배우 추출은 여전히 휴리스틱입니다.
여러 배우가 출연하는 작품이나 알 수 없는 태그를 완전하게 보존하는 파서는 아닙니다.
JAVGURU 자동 이동은 브라우저의 javascript 주소 실행 정책에 따라 실패할 수 있습니다.
검색 실패 시 원본 파일을 유지하거나 오류를 기록하며, 검증을 우회하지 않습니다.
기존처럼 인식되지 않은 제목/태그는 표준 파일명에서 제거될 수 있습니다.
